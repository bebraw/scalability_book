# Vibe Coding

The purpose of this part of the book and the included project is to show you both the joy and the pain of vibe coding. While fast, vibe coding also comes with a terrible cost as you will find out. This can be acceptable for prototypes, but can become a liability for projects that turn commercial. Besides vibe coding, we'll consider questions like what is scalability and what is the architecture of the web as both have implications on how we design and implement scalable web applications.
