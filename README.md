# Elements of Scalable Web Applications

This is the course book for the [Designing and Building Scalable Web Applications](https://fitech101.aalto.fi/en/courses/designing-and-building-scalable-web-applications) course held at Aalto University. The new course book is hosted at [scalableweb.dev](https://scalableweb.dev/).

## Website

Markdown source files live under [book/](book/). The public website is generated from those chapters and deployed at [scalableweb.dev](https://scalableweb.dev/).

Development, preview, feedback, and deployment notes are in [docs/development.md](docs/development.md).

## Feedback comments

The deployed site supports paragraph-level feedback. Setup details are in [docs/feedback-setup.md](docs/feedback-setup.md), and the local review workflow is documented in [docs/development.md](docs/development.md).
