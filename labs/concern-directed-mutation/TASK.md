# Detect one concern

Read README.md and SPEC.md, choose one named concern, and add one black-box test to `starter.test.ts`.
Keep `tracker.ts` and `run.ts` unchanged.
Preserve the starting results, then run the same tests against baseline, the selected mutant and storage-refactor.
Record the distinguishing assertion and one consequential decision about the observation boundary.
Other exercises are independent and require no changes for this task.
