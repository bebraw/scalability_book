# Course Project Specifications

The course uses one common application contract and three phase-specific development setups:

1. [Common project specification](00_common_project.md) — required behavior, technical freedom, acceptance scenarios, transfer policy, evidence, and cross-team audit.
2. [Construct](01_construct.md) — implementation A with a locally hosted single agent.
3. [Reconstruct](02_reconstruct.md) — implementation B with a foundation-model single agent.
4. [Deconstruct](03_deconstruct.md) — implementation C with an agent fleet, a trace-based debugging view of the fleet itself, and the final comparison.

Read the common specification together with the current phase specification.

These files are a working draft. The shared runtime workload, audit change probes, fleet-trace transformation example, exact model environments, and grading weights still need to be finalized.
